# Habit Tracker

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Productivity Tool](https://img.shields.io/badge/productivity-tool-green.svg)]()

A habit tracking CLI with streaks and detailed reports.

## ✨ Features

- **Track Habits** - Create and manage daily habits
- **Streaks** - Track current and longest streaks
- **Daily Check-in** - Quick daily check-in
- **Categories** - Organize habits by category
- **Reports** - Weekly/monthly progress reports
- **Calendar View** - Visual calendar of habit completion
- **Reminders** - Get reminded to check in
- **Rich UI** - Beautiful colored terminal output

## 📦 Installation

```bash
git clone https://github.com/Master-626/habit-tracker.git
cd habit-tracker
pip install .
```

## 🚀 Quick Start

```bash
# Add a habit
habit add "Exercise"

# Check in today
habit checkin "Exercise"

# List habits
habit list
```
